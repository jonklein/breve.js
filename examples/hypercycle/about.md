A **hypercycle** is a ring of molecules where each one helps the next copy itself (1 helps 2, 2 helps 3, ... 5 helps 1). [Eigen and Schuster](https://en.wikipedia.org/wiki/Hypercycle_(chemistry)) proposed it as a way for life's first molecules to cooperate: rivals crowd each other out, but a ring needs every member, so none can win alone.

Each cell holds a mixture of five chemicals (one color each) that adds up to 1. On a surface they chase each other around in spiral waves.

### What to try
- **help from the one before** is the cooperation. Set it to 0 and the pattern washes out.
- **copying without help** is how fast each grows alone; **spreading** moves chemicals into neighbors.
- **step size** and **small steps per tick** only change how fast it runs. **color contrast** only changes the picture.
- Press **Reset** to start from a new random mixture.
